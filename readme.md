# 📘 SimpleBook - Online Bookstore Management System

SimpleBook is a beginner-friendly PHP & MySQL web application that allows users to browse, purchase, and manage books in an online bookstore. It also includes admin functionality to manage inventory and view orders.

---

## ✨ Features

- User Registration & Login
- Browse Books by Genre/Author
- Purchase Books & View Order History
- Admin Dashboard for Book Management
- Basic Inventory & Stock Control

---

## 🛠️ Tech Stack

- PHP (Vanilla)
- MySQL
- HTML/CSS (Bootstrap optional)
- JavaScript (optional enhancements)
